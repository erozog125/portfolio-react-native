# Portafolio Personal en React Native

## Descripción

Este proyecto consiste en una aplicación móvil desarrollada con **React Native** y **Expo**.  
La interfaz simula la pantalla de un teléfono móvil y presenta un portafolio personal con información del desarrollador, una breve descripción, proyectos destacados y estudios realizados.

El diseño utiliza una estética minimalista con tonos azul-gris, tarjetas redondeadas, sombras y una estructura visual limpia.

---

## Tecnologías utilizadas

- React Native
- Expo
- JavaScript
- Componentes nativos:
  - View
  - Text
  - Image
  - ScrollView
  - Pressable
  - StyleSheet
  - StatusBar
