# Workshop: Portafolio Personal con Expo (Web)

Este proyecto es una práctica de maquetación móvil utilizando una plantilla base en blanco. El objetivo es que usted construya y personalice su portafolio profesional aprovechando las capacidades de **React Native** y **Expo**.

## 📋 Instrucciones de Inicio y Entrega

Siga este flujo de trabajo para configurar su entorno y subir sus evidencias:

### 1. Acceso al Repositorio

* Acepte la invitación que recibirá en su correo electrónico o directamente en su dashboard de GitHub para obtener permisos de edición.

### 2. Configuración Local

* Clone el proyecto desde la rama `main`.
* **IMPORTANTE:** Una vez clonado, navegue hasta la carpeta del proyecto en su terminal y ejecute el siguiente comando para instalar todas las librerías necesarias:
```bash
npm install

```


*(No omita este paso, ya que las dependencias no se incluyen en el clonado inicial).*

### 3. Desarrollo y Ramas

* Cree una rama propia para trabajar. El nombre debe seguir el formato: `nombre-apellido`.
* El desarrollo se basa en una **plantilla en blanco**. Puede agregar, modificar o eliminar las secciones que considere necesarias para su perfil.
* **Nota:** En esta fase solo trabajaremos en la **maquetación visual**; no es necesario implementar lógica de programación.

---

## 🚀 Comandos Útiles

Para visualizar su progreso en el navegador, utilice el siguiente comando:

```bash
npm run web

```
